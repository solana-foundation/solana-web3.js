    Class Keypair

    An account keypair backed by WebCrypto.

    Implements Kit's KeyPairSigner (and therefore MessagePartialSigner and TransactionPartialSigner), so instances can be passed directly to Kit APIs and generated program clients that accept a TransactionSigner or KeyPairSigner.
