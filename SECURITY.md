# Security Policy

## Reporting Security Problems

**DO NOT CREATE A GITHUB ISSUE** to report a security problem.

Instead please use this [Report a Vulnerability](https://github.com/solana-foundation/solana-web3.js/security/advisories/new) link.

Provide a helpful title, a detailed description of the problem, and an exploit proof-of-concept. Speculative submissions without a proof-of-concept will be closed with no further consideration.

Expect a response as fast as possible in the advisory, typically within 72 hours.
